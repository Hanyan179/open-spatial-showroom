## 可执行命令与环境边界

命令来源为 [package.json](../package.json) 与现有 [CI 工作流](../.github/workflows/ci.yml)。

| 用途 | 命令 | 边界 |
| --- | --- | --- |
| 安装 | `npm ci` | Node.js >=22.12.0；首次安装需要联网 |
| 本地开发 | `npm run dev` | 默认本机 5217 端口；需要支持 WebGL 2 的浏览器 |
| 完整重建 | `npm run build:all` | 重建示例媒体、GLB、内嵌产品模块及主应用，会写入生成物 |
| 自动化测试 | `npm test` | Node 测试套件，不代替视觉、性能及实际设备验收 |
| 公开内容卫生 | `npm run check:public` | 常见敏感内容与本地引用检查，不是完整安全或权利审计 |
| 构建预览 | `npm run preview` | 默认本机 5218 端口；先完成构建 |

默认配置位于 [public/showroom.config.json](../public/showroom.config.json)，没有要求配置服务端环境变量或 API 密钥的默认启动步骤。自定义远程服务的权限、跨域与认证由部署者处理，不能将凭证写入前端配置。
