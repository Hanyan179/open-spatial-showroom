# 验证记录

本记录对应首个通用公开版本，验证日期为 2026-09-11。运行环境为 macOS、Node.js 24.19.0、Vite 6.4.3，以及应用内 Chromium 浏览器。

已从全新检出目录完成 `npm ci`、完整重建、70 项测试与公开检查，未依赖本机原项目文件。

## 自动化检查

- `npm run build:all` 通过：生成 18 张房间产品示意图、24 张概念插画、9 个独立 GLB 和产品探索器、主应用构建。
- `npm test`：70 项通过，0 项失败。覆盖场景注册、内容引用、目录与导览、返回状态、分类检索、模型批处理、资源释放、双语标识、飞行朝向和机械运动约束。
- 架构检查：9 个场景、18 条房间产品、11 类动作、8 类内容面板、71 个当前入口依赖模块，无缺失引用或依赖循环。
- `npm run check:public`：通过公开文件卫生与本地媒体引用检查；9 个 GLB 不含嵌入图片。
- 依赖审计：更新兼容补丁后无已知漏洞。审计结论仅代表当时的依赖数据库。

## 发布边界与尚未验证

公开版本从独立目录重新建立提交历史，仅包括通用源码、重新生成的模型、原创示例插画和声明过来源的资源。企业资料、真实产品图片、原始档案、公司标志与私有部署配置不在该版本中。

本轮未进行一小时压力测试、真实大屏触摸验收、完整硬件帧率基准、移动端、头显或第三方后台集成验收。默认没有视频，不将代码中的视频支持等同于真实视频素材播放已验收。媒体与远程接口需由维护者接入后按实际数据测试。

CI 工作流在每次推送和合并请求时重建并运行测试；它不能代替人工视觉检查或现场设备验收。
